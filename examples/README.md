# Examples

Runnable workflows that show how to integrate **sference-sdk** with common orchestration tools.

| Path | Description |
|------|-------------|
| [prefect/](prefect/) | Prefect flows using batch `/v1/responses` (1h completion window) |

Install example dependencies from the oss repo root:

```bash
uv sync --group dev --group examples
```

Each subdirectory has its own README with environment variables and run commands.
